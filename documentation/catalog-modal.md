# Документация: Всплывающее меню Каталога (Desktop)

В данном документе описана архитектура и логика работы полноэкранного модального окна каталога, которое открывается по кнопке «Каталог» в шапке сайта.

## Структура файлов

В процессе реализации были затронуты/созданы следующие файлы:

- **HTML**: `catalog.html` (добавлена разметка `<div class="catalog-modal">` и добавлен `id="catalog-btn"` к кнопке).
- **CSS**: `css/modules/catalog-modal.css` (создан новый файл, подтягивается через `global.css`).
- **JavaScript**: `js/modules/catalog-modal.js` (создан новый модуль, инициализируется в `main.js`).
- **Иконки**: Используются `hamburger.svg` и `close-light.svg` (белый крестик для открытого состояния кнопки).

## Разметка (HTML)

Модальное окно состоит из контейнера `.catalog-modal`, который технически является оверлеем (`position: fixed`).
Внутри него располагается `.catalog-modal__inner` (grid-сетка на 2 колонки):

1. **Левая колонка (сайдбар)**: `.catalog-modal__sidebar`. Содержит список всех 14 корневых категорий (`<a class="catalog-modal__category-link" data-category="...">`). У ссылок есть атрибут `data-category`, с помощью которого JS понимает, какой контент нужно показать.
2. **Правая колонка (контент)**: `.catalog-modal__content`. Содержит набор блоков `.catalog-modal__panel`. У каждой панели есть `data-panel="..."`, соответствующий `data-category`. Каждая панель имеет трехколоночную верстку (подкатегории, прочие списки услуг и промо-блок с картинкой).

У активной категории и активной панели стоит класс `is-active`. Изначально по умолчанию `is-active` прописан для категории «Печи для бани».

## Стилизация (CSS)

Ключевые особенности CSS, на которые стоит обратить внимание:

1. **Позиционирование с учетом Header-а**:
   Модальное окно опускается вниз от верха экрана, чтобы не перекрывать шапку.
   - В обычном состоянии делается отступ `padding-top: 160px` (с учетом `header__top` и `header__middle`).
   - Если шапка прилипает к верху экрана (состояние sticky), у контейнера `.header` появляется класс `.is-sticky`. Через CSS sibling combinator (`.header.is-sticky ~ .catalog-modal`) отступ и максимальные высоты скролящихся областей пересчитываются (до `72px`).

2. **Независимый скролл**:
   Само модальное окно жестко зафиксировано (`overflow: hidden`), системный скролл заблокирован на уровне `body` (`body.catalog-modal-open { overflow: hidden; }`).
   Сайдбар и контентная панель имеют независимую прокрутку (`overflow-y: auto`, `max-height: calc(...)`).

3. **Кастомный скроллбар**:
   Скроллбары для сайдбара и контентной зоны стилизованы: задана толщина в `3px` и серый цвет `#E7E7E7`. Для Webkit использованы псевдоэлементы `::-webkit-scrollbar*`, а для Firefox — свойства `scrollbar-width` и `scrollbar-color`.

4. **Активное состояние категорий**:
   При наведении на категории применяется фон `#f9fafb`, появляется левый бордер акцентного цвета, иконка chevron становится более контрастной. Задается это в классах `.catalog-modal__category-link:hover` и `.catalog-modal__category-link.is-active`.

## Логика работы (JavaScript)

Вся логика инкапсулирована в `initCatalogModal()` (`catalog-modal.js`):

1. **Слушатели событий кнопки**: Клик по `#catalog-btn` включает/выключает класс `is-open` у модалки и блокирует скролл у страницы.
2. **Смена иконки в кнопке**: При открытии каталога иконка внутри кнопки «Каталог» меняется с бургера на `close-light.svg` (белый крестик). При закрытии возвращается обратно. Сам дизайн красной кнопки остается неизменным, меняется только `.src` у вложенного `<img>`.
3. **Клавиатура**: Добавлен слушатель на весь документ (`document.addEventListener("keydown")`), который закрывает модальное окно при нажатии клавиши **Escape**.
4. **Переключение панелей (Hover)**: На ссылках категорий `.catalog-modal__category-link` висит слушатель события `mouseenter`. При срабатывании скрипт считывает `data-category`, снимает класс `is-active` со всех элементов и вешает его на текущую ссылку категории и на `.catalog-modal__panel`, чей атрибут `data-panel` совпадает с запрошенным.

## Дальнейшие шаги и поддержка

- Если в будущем добавятся новые категории: нужно добавить соответствующий `<li>` элемент в сайдбаре с уникальным `data-category`, и добавить `div.catalog-modal__panel` с точно таким же `data-panel`.
- В мобильной версии этот десктопный каталог обычно скрывается (регулируется медиа-запросами и логикой мобильного меню), данная реализация сфокусирована исключительно на десктопном отображении.
