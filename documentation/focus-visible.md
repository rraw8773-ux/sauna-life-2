# Доступная клавиатурная навигация (Focus-Visible Module)

Документ описывает логику, архитектуру, интерактивное поведение и CSS/JS-контракт модуля `:focus-visible`, предназначенного для разделения фокуса клавиатуры от фокуса мыши или тач-событий.

---

## 1. Назначение фичи

В премиальном дизайне интернет-магазина **Sauna Life** важно соблюдать баланс между эстетикой и доступностью:
1. **Исключение визуального шума для мыши/тача**: когда пользователь кликает мышкой по кнопкам, карточкам, табам или тегам, стандартное синее/черное кольцо фокуса вокруг элементов скрывается, сохраняя чистоту премиального интерфейса.
2. **Абсолютная доступность для клавиатуры (WCAG / a11y)**: когда пользователь перемещается по сайту с помощью клавиш `Tab` или стрелок, сфокусированный элемент получает четко различимую, красивую и фирменную рамку фокуса золотистого цвета (`--color-accent`), что позволяет легко ориентироваться на странице без мыши.

Для этого реализован гибридный подход: нативный CSS-селектор `:focus-visible` с автоматическим JavaScript-полифилом для гарантированной поддержки во всех браузерах.

---

## 2. Связанные файлы

- **Стили (CSS):**
  - `css/base/utilities.css` — содержит глобальный сброс аутлайнов при кликах и стилизацию премиального фокуса.
- **Скрипты (JS):**
  - `js/modules/focus-visible.js` — модуль-полифил, который отслеживает метод ввода пользователя и добавляет/удаляет класс `.focus-visible` и дата-атрибут `data-focus-visible-added`.
- **Точки входа страниц (подключение):**
  - `js/main.js` — глобальная точка входа.
  - `js/pages/catalog.js` — страница каталога.
  - `js/pages/product.js` — детальные страницы товаров.
  - `js/pages/wishlist.js` — страницы избранного.

---

## 3. Алгоритм работы JavaScript

Полифил определяет тип взаимодействия (модальность) на основе следующих событий:

1. **Клавиатурный ввод**: Любое нажатие клавиши (кроме системных модификаторов `Shift`, `Alt`, `Control`, `Meta` самих по себе) переключает состояние в `hadKeyboardEvent = true`.
2. **Мышь / Тач**: События `mousedown`, `pointerdown` и `touchstart` мгновенно сбрасывают состояние в `hadKeyboardEvent = false`.
3. **Обработка фокуса (Capturing Phase)**:
   - При срабатывании события `focus` на любом элементе страницы, скрипт проверяет текущее состояние.
   - Если фокус получен в результате клавиатурного ввода **ИЛИ** элемент является текстовым полем ввода (`<input>`, `<textarea>`, `contenteditable`), ему добавляется CSS-класс `.focus-visible` и атрибут `data-focus-visible-added`.
   - Текстовые поля получают индикатор фокуса всегда, так как для взаимодействия с ними клавиатура обязательна в любом режиме.
4. **Обработка потери фокуса (Capturing Phase)**:
   - При событии `blur` класс `.focus-visible` и дата-атрибут удаляются с элемента.

Использование фазы перехвата (`true`) позволяет полифилу надежно работать с динамически подгружаемыми (AJAX/JS) элементами без необходимости повторной инициализации.

## 4. CSS-контракт

Дизайн фокусного кольца полностью интегрирован с дизайн-системой Sauna Life:

```css
/* 1. Сбрасываем стандартный браузерный контур при обычном клике/таче */
.js-focus-visible :focus:not(.focus-visible) {
  outline: none !important;
  box-shadow: none !important;
}

/* 2. Задаем премиальное фокусное состояние для клавиатурной навигации */
.js-focus-visible .focus-visible {
  outline: 2px solid var(--color-accent, #e3a93b) !important;
  outline-offset: 2px !important;
  box-shadow: 0 0 0 4px rgba(227, 169, 59, 0.15) !important;
}

/* Нативный фолбек для современных браузеров с полной поддержкой */
@supports selector(:focus-visible) {
  :focus:not(:focus-visible) {
    outline: none !important;
    box-shadow: none !important;
  }
  :focus-visible {
    outline: 2px solid var(--color-accent, #e3a93b) !important;
    outline-offset: 2px !important;
    box-shadow: 0 0 0 4px rgba(227, 169, 59, 0.15) !important;
  }
}
```

### Визуальные характеристики фокуса:
- **Цвет**: Акцентное золото Sauna Life (`--color-accent`).
- **Сдвиг (`outline-offset`)**: `2px` наружу от элемента для чистоты восприятия границ.
- **Мягкое свечение (`box-shadow`)**: полупрозрачный ореол золотого цвета (`rgba(227, 169, 59, 0.15)`) шириной `4px` для создания ощущения глубины и объемности.

## 5. Интеграция в проект

Модуль подключается как автоинициализирующийся ES-модуль. Достаточно импортировать его один раз в начале любой точки входа:

```javascript
import "../modules/focus-visible.js";
```

При импорте скрипт автоматически добавляет класс `.js-focus-visible` на элемент `<html>` для активации соответствующих CSS-правил.
