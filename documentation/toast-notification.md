# Всплывающие уведомления (Toast Notifications Module)

Документ описывает логику, архитектуру, интерактивное поведение и правила интеграции автономного кросс-страничного модуля всплывающих уведомлений (Toasts). 

## 1. Назначение фичи

Модуль Toasts представляет собой легкую, производительную и визуально премиальную систему информирования пользователя. Первоочередно она используется для уведомления о добавлении/удалении товаров из Избранного, однако архитектурно спроектирована как **абсолютно универсальное решение**, поддерживающее любые типы сообщений.

Основные характеристики:
1. **Премиальный дизайн (Glassmorphism)**: глубокий размытый фон (`backdrop-filter`), ультратонкие полупрозрачные границы и аккуратные шрифтовые контрасты.
2. **Динамический стек (Queue)**: уведомления стакаются снизу вверх в левой части экрана, плавно сменяя друг друга.
3. **Адаптивность (Mobile-first placement)**: на мобильных устройствах уведомления автоматически приподнимаются над плавающей нижней навигацией (`bottom: 72px` вместо `24px`), сохраняя левое выравнивание и премиальную анимацию вылета.
4. **Универсальные типы алертов**: поддержка типов `success` (успех), `info` (информация), `warning` (предупреждение), `error` (ошибка) и `remove` (акцентный тип удаления).
5. **Интерактивное закрытие**: плашка мгновенно растворяется по клику (тапу) в любом месте своей площади.

## 2. Связанные файлы

- **Стили (CSS):**
  - `css/modules/toast.css` — BEM-стилизация всплывающих уведомлений, адаптивные медиа-запросы, ключевые кадры анимаций.
  - `css/global.css` — регистрирует модуль через `@import "modules/toast.css";`.
- **Скрипты (JS):**
  - `js/modules/toast.js` — синглтон-класс `Toast` (управляет DOM-стеком, SVG-иконками, таймерами закрытия).
  - `js/modules/favorites-toast-controller.js` — специализированный адаптер-контроллер, связывающий кнопки-сердечки на всех страницах с Toast-движком.
  - `js/pages/catalog.js`, `js/pages/product.js`, `js/pages/wishlist.js` — точки входа страниц, инициализирующие контроллер избранного.

## 3. HTML-контракт

Движок генерирует HTML-разметку динамически. Вручную добавлять контейнеры в код страниц не требуется.

### Стек-контейнер (создается при первом вызове):
```html
<div class="toast-container"></div>
```

### Структура отдельной плашки уведомления:
```html
<div class="toast toast--success">
  <div class="toast__icon">
    <!-- Inline SVG (зависит от type) -->
    <svg>...</svg>
  </div>
  <div class="toast__message">Товар добавлен в избранное</div>
</div>
```

### Модификаторы типов сообщений (`toast--[type]`):
- `toast--success` — зеленый акцент иконки (добавление в корзину/избранное).
- `toast--info` — синий акцент (информирование о статусе).
- `toast--warning` — оранжевый акцент (предупреждения системы).
- `toast--error` — красный акцент (системные ошибки).
- `toast--remove` — фирменный терракотовый/оранжевый акцент (`--color-accent`) для удаления из списков.

## 4. CSS-контракт

Дизайн тостов базируется на глобальных CSS-переменных проекта:

```css
:root {
  /* Переменные проекта, используемые в Toasts */
  --color-dark: #0a0a0a;
  --color-success: #22c55e;
  --color-blue: #0066ff;
  --badge-red: #ef4444;
  --badge-orange: #f97316;
  --color-accent: #e55c1e;
}
```

### Спецификация анимаций:
- **Появление**: плавное скольжение слева направо с легким увеличением масштаба:
  - `transform: translateX(-120%) scale(0.9)` $\rightarrow$ `transform: translateX(0) scale(1)`
  - Временная функция: `cubic-bezier(0.16, 1, 0.3, 1)` (премиальный вылет за 450мс).
- **Плавный сдвиг**: при удалении нижнего тоста, верхние плавно опускаются благодаря нативному CSS Flexbox-распределению и `transition: transform 0.3s ease`.
- **Исчезновение**: плашка растворяется и улетает влево:
  - `opacity: 0`
  - `transform: translateX(-100%) scale(0.95)`

## 5. JS-контракт (API модуля)

### Универсальный класс: `Toast` (`js/modules/toast.js`)

Использует статический метод `show()` для вызова уведомлений из любого скрипта проекта.

#### Сигнатура метода:
```javascript
import { Toast } from "../modules/toast.js";

Toast.show({
  message: "Ваше сообщение",  // Текст уведомления (обязательный)
  type: "success",            // success | info | warning | error | remove (по умолчанию 'success')
  duration: 3000              // Время отображения в мс (по умолчанию 3000, 0 — без автозакрытия)
});
```

---

### Контроллер-адаптер: `favorites-toast-controller.js`

Использует **делегирование событий** на уровне `document` для перехвата кликов на кнопки добавления в избранное (поддерживает AJAX-подгрузку товаров без повторной инициализации).

#### Алгоритм работы:
1. Перехватывает клики по селекторам сердечек:
   - `.product-card__action-btn` — карточки товаров в каталоге.
   - `.product-hero__gallery-action-btn` — кнопка над галереей на детальной странице товара.
   - `.wishlist-card__like-btn` — карточки на странице вишлиста.
2. Проверяет наличие внутренней иконки `img[src*='like']`.
3. Запускает функцию `handleLikeToggle(button, img)`:
   - Если у картинки в пути есть `like-fill.svg` (активно):
     - Меняет путь на `like.svg` (выключает заливку).
     - Убирает у кнопки класс `.is-active`.
     - Запускает `Toast.show` со статусным типом `remove` и сообщением *"Товар удалён из избранного"*.
   - Если у картинки в пути `like.svg` (неактивно):
     - Меняет путь на `like-fill.svg` (включает заливку).
     - Добавляет кнопке класс `.is-active`.
     - Запускает `Toast.show` со статусным типом `success` и сообщением *"Товар добавлен в избранное"*.

## 6. Правила адаптива и брейкпоинты

Модуль следует строгой сетке адаптива проекта:

- **Десктопы (> 767px)**:
  - Контейнер позиционируется в левом нижнем углу: `bottom: 24px; left: 24px`.
  - Максимальная ширина плашки: `400px`.
- **Планшеты и Смартфоны (<= 767px)**:
  - Контейнер приподнимается: `bottom: 72px` (для бесконфликтного отображения над мобильным навигационным таб-баром `.mobile-nav`).
  - Расположение остается левосторонним (`left: 24px`), плашки сохраняют вылет слева.
- **Компактные мобильные экраны (<= 479px)**:
  - Контейнер: `left: 12px; right: 12px; bottom: 72px`.
  - Максимальная ширина растягивается под размер экрана: `max-width: calc(100% - 24px)`.

## 7. Ограничения и Безопасность

1. **Имена иконок**: Автоматическая логика переключения путей картинок завязана на ключевые фразы `like.svg` и `like-fill.svg`. При переименовании файлов иконок необходимо обновить регулярное выражение замены в `favorites-toast-controller.js`.
2. **ES-Модули**: Скрипты `toast.js` и `favorites-toast-controller.js` написаны по стандарту ES6 Modules. При их импорте на страницах убедитесь, что тег скрипта содержит атрибут `type="module"`:
   ```html
   <script type="module" src="./js/pages/catalog.js"></script>
   ```
3. **Безопасное автозакрытие**: Движок тостов гарантированно удаляет слушатели анимации и ссылки на DOM-элементы из памяти по истечении таймера, предотвращая утечки памяти (Memory Leaks) при длительных сессиях пользователя.
