# Документация: Мобильное меню (Бургер-меню)

В этом документе описана реализация нового выезжающего слева мобильного меню для сайта, которое появляется по клику на кнопку-бургер.

## 1. Структура файлов

Для реализации функционала мобильного меню были добавлены и изменены следующие файлы:

### Новые файлы:

- `css/modules/mobile-menu.css` — стили для самого меню, оверлея, анимации выезда слева и внутреннего контента (навигации, контактов).
- `js/modules/mobile-menu.js` — логика открытия и закрытия меню.

### Изменённые файлы:

- `catalog.html` — основная разметка (добавлен `id="burger-btn"` к кнопке открытия и сам блок `<div id="mobile-menu" class="mobile-menu">`).
- `css/global.css` — подключён файл стилей (`@import "modules/mobile-menu.css";`).
- `js/main.js` — подключён и инициализирован скрипт `initMobileMenu()`.

---

## 2. HTML-структура (`catalog.html`)

### Кнопка открытия

Для таргетинга события клика был добавлен идентификатор `id="burger-btn"` к кнопке `.header__burger`:

```html
<button
  class="header__burger"
  id="burger-btn"
  type="button"
  aria-label="Открыть меню"
  aria-expanded="false"
>
  <img src="assets/icons/header/hamburger.svg" alt="" />
</button>
```

### Разметка меню (панель и оверлей)

Добавлен блок перед `#catalog-modal` (в конце `<body>` / после `<header>`):

- `.mobile-menu` — скрытый корневой контейнер-обёртка поверх всего сайта.
- `.mobile-menu__overlay` — тёмный полупрозрачный фон.
- `.mobile-menu__panel` — сама белая боковая панель шириной до 340px с контентом:
  - **Шапка** (`.mobile-menu__header`): логотип и кнопка закрытия ✕.
  - **Навигация** (`.mobile-menu__nav`): ссылки меню, бейдж "Распродажа", разделители.
  - **Контакты** (`.mobile-menu__contacts`): телеграм, телефоны с расписанием и кнопка заказа звонка.

---

## 3. Стилизация (`mobile-menu.css`)

- **Отображение и Z-index**: Меню фиксировано поверх всего (`position: fixed; inset: 0; z-index: 1100;`). Когда не активно, `pointer-events: none; visibility: hidden;`.
- **Класс состояния**: При открытии родительскому `.mobile-menu` добавляется класс `.is-open`.
- **Анимация оверлея**: Смена прозрачности (`opacity: 0` -> `opacity: 1`) с плавным `transition`.
- **Анимация выезда**: Панель изначально спрятана слева за экраном (`transform: translateX(-100%);`). При классе `.is-open` она плавно выезжает (`transform: translateX(0);`).

---

## 4. JavaScript логика (`mobile-menu.js`)

Логика максимально проста и изолирована в модуль `initMobileMenu()`.

**Как это работает:**

1.  Находим элементы: кнопку-бургер, оверлей, кнопку-крестик и сам контейнер.
2.  **`openMenu()`**:
    - Добавляет класс `is-open` контейнеру.
    - Устанавливает `aria-hidden="false"`.
    - Устанавливает `aria-expanded="true"` у кнопки.
    - Блокирует скролл страницы: `document.body.style.overflow = "hidden"`.
3.  **`closeMenu()`**:
    - Убирает класс `is-open`.
    - Убирает `overflow = "hidden"` у `body`, возвращая скролл.
4.  **Обработчики событий**:
    - Клик по `#burger-btn` → открывает меню.
    - Клик по крестику закрытия или тёмному оверлею → закрывает меню.
    - Нажатие клавиши `Escape` (если меню открыто) → закрывает меню.

---

## 5. Как менять / расширять

- **Изменение ширины панели**: в `mobile-menu.css` измените `max-width: 340px` у `.mobile-menu__panel`.
- **Чтобы панель выезжала справа (как было изначально)**: в `mobile-menu.css` измените `left: 0;` на `right: 0;` и `transform: translateX(-100%);` на `transform: translateX(100%);`.
- **Добавление новых ссылок**: просто добавьте новые `<li><a class="mobile-menu__nav-link">...</a></li>` в список `.mobile-menu__nav-list` внутри разметки. Стили применятся автоматически.
