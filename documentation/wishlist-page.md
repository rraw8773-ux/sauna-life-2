# Страница Избранного (Wishlist Page)

Документ описывает логику, интерактивное поведение и структуру ES-модулей для страницы Избранного (как заполненной `wishlist.html`, так и пустой `wishlist-empty.html`).

## 1. Назначение фичи

Страница Избранного отображает список товаров, которые пользователь отложил (добавил в избранное). Включает в себя:
1. Отображение сохраненных товаров с их характеристиками, ценами и кнопками управления.
2. Возможность мгновенного плавного удаления товара из списка непосредственно с этой страницы при клике по заполненному сердечку (`.wishlist-card__like-btn`).
3. Динамический переход в состояние «В Избранном пока пусто» с анимацией плавного появления при удалении последнего товара.
4. Дополнительный переиспользуемый блок рекомендаций (`.products-widget`) с табами и адаптивными слайдерами.

## 2. Связанные файлы

- **HTML страницы:**
  - `wishlist.html` — заполненная страница избранного
  - `wishlist-empty.html` — пустая страница избранного
- **CSS стили:**
  - `css/pages/wishlist-page.css` — главная страничная точка входа стилей (содержит нативные импорты табов, рекомендаций, промо-блока и вишлиста)
  - `css/pages/product/product-slider.css` — стили кнопок вкладок (`.btn-tab`) и базовых элементов слайдера
  - `css/pages/wishlist/wishlist-list.css` — стили списка и карточек избранного
  - `css/pages/wishlist/wishlist-empty.css` — стили пустого состояния избранного
- **JavaScript файлы:**
  - `js/pages/wishlist.js` — главная страничная точка входа ES-модулей
  - `js/modules/sticky-header.js` — модуль липкой шапки
  - `js/modules/offcanvas.js` — боковая панель
  - `js/modules/mobile-menu.js` — мобильное бургер-меню
  - `js/modules/mobile-catalog-menu.js` — мобильное меню категорий
  - `js/modules/catalog-modal.js` — десктопное модальное меню каталога
  - `js/modules/tabs.js` — универсальный плагин вкладок
  - `js/modules/products-widget.js` — инициализация слайдера Slick в блоке рекомендаций

## 3. HTML-контракт

Основные секции в HTML-разметке:

- `.wishlist-list` — секция списка товаров (отображается при наличии элементов).
- `.wishlist-empty` — секция пустого списка с иконкой и призывом к действию (скрыта через `style="display: none"` в `wishlist.html`).
- `.wishlist-list__items` — контейнер-сетка для карточек товаров.
- `.wishlist-card` — блок карточки избранного товара:
  - `.wishlist-card__like-btn` — кнопка удаления из избранного (сердечко).
  - `.wishlist-card__cart-btn` — кнопка добавления товара в корзину.

## 4. CSS-контракт

Ключевые стили анимаций и переключений определяются свойствами:

- `is-visible` / `is-active` — используются для переключения табов в блоке рекомендаций.
- Анимация удаления карточки (`wishlist-card`) обеспечивается динамическими inline-стилями:
  - `transition: all 0.4s cubic-bezier(0.4, 0, 0.2, 1)`
  - `opacity: 0`
  - `transform: scale(0.9) translateY(15px)`
- Анимация появления пустого экрана (`wishlist-empty`):
  - `transition: all 0.5s cubic-bezier(0.34, 1.56, 0.64, 1)`
  - `opacity: 1`
  - `transform: translateY(0)`

## 5. JS-контракт

### Точка входа: `js/pages/wishlist.js`

Инициализирует глобальные компоненты общего интерфейса и запускает локальный скрипт страницы.

### Функция инициализации: `initWishlistPage()`

Локальная функция, управляющая кликами и анимацией удаления карточек:
- Отслеживает клики на `.wishlist-card__like-btn` посредством делегирования событий на общем контейнере `.wishlist-list__items`.
- Запускает плавную анимацию скрытия карточки.
- Физически удаляет элемент из DOM по завершении анимации.
- Проверяет количество оставшихся карточек `.wishlist-card`.
- Если карточек не осталось:
  1. Плавно скрывает секцию `.wishlist-list` (opacity до 0 за 300мс).
  2. Переключает `.wishlist-list` на `display: none`.
  3. Переводит `.wishlist-empty` в `display: block` с одновременным запуском премиального Bounce-эффекта появления (`translateY(20px)` -> `translateY(0)`).

## 6. Правила адаптива и интерактивных состояний

- Слайдер в блоке рекомендаций (`.products-widget__slider`) адаптируется под размеры экранов в `js/modules/products-widget.js`:
  - Десктопы: `slidesToShow: 4`
  - Планшеты (<= 1023px): `slidesToShow: 3.15` (с эффектом «выглядывающей» следующей карточки для тач-скролла)
  - Мобильные (<= 767px): `slidesToShow: 2.15` (скрыты стрелки, включен свободный тач-свайп)
  - Компактные (<= 479px): `slidesToShow: 1.5`
- Отслеживание нажатий на вкладки рекомендаций плавно центрирует выбранный пункт меню на мобильных экранах.

## 7. Ограничения

- **Порядок подключения скриптов:** Точка входа `wishlist.js` является ES-модулем (`type="module"`), поэтому она должна подключаться ПОСЛЕ legacy-библиотек (jQuery, Slick, script.js), так как Slick-слайдеру в `.products-widget` требуется предварительно загруженный jQuery.
- **Безопасность выполнения:** Инициализатор защищен проверками `if (!document.querySelector(...))` и не падает с ошибками на пустом вишлисте (`wishlist-empty.html`), где список товаров изначально отсутствует.
