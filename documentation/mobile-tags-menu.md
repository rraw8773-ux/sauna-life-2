# Документация: Мобильное меню тегов и оффканвас (Tags Offcanvas)

## Описание функционала

Для блока тегов (категорий) на мобильных устройствах (< 768px) был реализован следующий функционал:

1. **Горизонтальный скролл:** Теги больше не оборачиваются на новые строки на мобильных устройствах. Вместо этого они выстраиваются в один ряд с возможностью горизонтальной прокрутки.
2. **Кнопка «Все»:** В начале списка появилась кнопка «Все», которая открывает модальное окно (offcanvas) снизу вверх.
3. **Оффканвас тегов:** Модальное окно содержит полный вертикальный список всех тегов с иконками, оформленный согласно мобильному дизайну.
4. **Скрытие кнопки «Еще»:** На мобильных устройствах кнопка «Еще» скрывается, так как элементы скроллятся горизонтально и могут быть полностью просмотрены в оффканвасе.

## Отсутствие дублирования HTML (DRY)

Раньше для модального окна на мобилке требовалось дублировать все теги. Теперь это работает автоматически.

В HTML мы задаем список тегов только **один раз** в основном блоке `<div class="tags"><ul class="tags__list">...</ul></div>`.

Оффканвас-контейнер для тегов в `catalog.html` содержит только пустой список:

```html
<div class="offcanvas offcanvas--mobile-only" id="tags-offcanvas">
  <!-- Шапка оффканваса -->
  ...
  <div class="offcanvas__body">
    <ul class="tags-menu" id="tags-offcanvas-menu"></ul>
  </div>
</div>
```

Скрипт `js/modules/tags.js` при инициализации (`initTags()`) вызывает функцию `populateTagsOffcanvas()`. Эта функция:

1. Берет все элементы из `.tags__list` (игнорируя кнопки «Все» и «Еще»).
2. Автоматически генерирует вертикальный список `li.tags-menu__item` с классами для модального окна.
3. Копирует `href`, иконки `<img>` и текст из оригинального списка.
4. Вставляет сгенерированный список внутри `#tags-offcanvas-menu`.
5. _Примечание:_ если у тега (например, бренда) нет иконки, функция создает специальный квадратный плейсхолдер с классом `.tags-menu__icon-placeholder`.

**Связь** между кнопкой и оффканвасом устанавливается через data-атрибут `data-target="tags-offcanvas"` на кнопке «Все».

## CSS Классы и Разметка

### 1. `offcanvas--mobile-only`

Этот модификатор был добавлен в `offcanvas.css`. Он нужен для standalone-оффканвасов (например, для тегов), которые не встроены в общую структуру (как, например, сайдбар с фильтрами, который превращается в блок на десктопе).
Класс `offcanvas--mobile-only` скрывает этот элемент полностью на десктопных разрешениях (>= 768px) через `display: none !important`.

### 2. `.tags-menu` (в `tags.css`)

Стили для вертикального списка внутри модального окна:

- `tags-menu__item`: элемент списка, имеет бордер снизу или скругленные края с отступами.
- `tags-menu__link`: внутренняя ссылка (flex, gap 8px, padding).
- `tags-menu__icon`: отображение квадратной иконки (28x28px) с фоном.

### 3. Горизонтальный скролл (`tags.css`)

Для `.tags__list` на `@media (max-width: 767px)`:

```css
.tags__list {
  flex-wrap: nowrap !important;
  overflow-x: auto;
  overflow-y: hidden;
  ...
}
```

## Как добавить новую категорию/бренд

Чтобы добавить новую категорию, нужно добавить **всего один** `<li>` элемент в главный список `.tags__list` в `catalog.html`.

**Пример элемента с иконкой:**

```html
<li class="tags__item">
  <a href="#" class="tags__link">
    <img
      src="assets/images/catalog/cats/my-icon.png"
      alt=""
      class="tags__icon"
    />
    Название категории
  </a>
</li>
```

**Пример бренда (без иконки):**

```html
<li class="tags__item">
  <a href="#" class="tags__link tags__link--brand">Название Бренда</a>
</li>
```

JS автоматически перехватит новый пункт и добавит его в модальное меню для мобильных пользователей. Никаких дополнительных действий в HTML не требуется.
