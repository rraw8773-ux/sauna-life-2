# Документация: Переключение вида каталога (Плитка / Список)

## Общее описание

Функционал переключения вида каталога позволяет пользователям изменять отображение карточек товаров между сеткой (grid) и списком (list). Выбранное состояние сохраняется в браузере пользователя с использованием `localStorage`, что обеспечивает сохранение выбранного вида при перезагрузке страницы или при повторном заходе на сайт.

---

## 1. JavaScript (Логика и хранение)

Основная логика находится в модуле `js/modules/view-toggle.js`.

**Ключевые особенности:**

- **Ключ в localStorage:** `catalogView`
- **Доступные значения:** `'grid'` | `'list'`
- **Значение по умолчанию:** `'grid'` (если пользователь зашел впервые или сбросил кеш)

Модуль экспортирует функцию `initViewToggle()`, которая:

1. Ищет обертку элементов переключения (`.catalog__view-toggle`) и сам контейнер сетки товаров (`.catalog__grid`).
2. Читает значение из `localStorage`.
3. Применяет нужный класс на контейнер сетки (добавляет `.catalog__grid--list`, если выбран вид списком).
4. Управляет активным классом на кнопках-переключателях (`.is-active`, `.catalog__view-btn--active`).
5. Навешивает обработчики событий `click` на кнопки, которые обновляют вид и записывают новое значение в `localStorage`.

### Подключение

Модуль инициализируется в главном файле `js/main.js`:

```javascript
import { initViewToggle } from "./modules/view-toggle.js";

document.addEventListener("DOMContentLoaded", () => {
  // ... другой код ...

  // Инициализация переключателя вида каталога
  if (document.querySelector(".catalog__view-toggle")) {
    initViewToggle();
  }
});
```

## 2. HTML (Разметка кнопок)

Кнопки переключения вида находятся в `catalog.html`. JS-модуль больше не использует data-атрибуты, а ориентируется на классы-модификаторы:

- Кнопка **Списком**: класс `.catalog__view-btn--list`
- Кнопка **Плиткой**: класс `.catalog__view-btn--grid`

**Важно:** Не нужно вручную прописывать класс активности (например, `.catalog__view-btn--active`) в исходном HTML. Модуль сам определит активную кнопку при загрузке страницы на основе `localStorage`.

Пример структуры кнопок:

```html
<div class="catalog__view-toggle">
  <!-- Кнопка списка -->
  <button
    class="catalog__view-btn catalog__view-btn--list"
    type="button"
    aria-label="Вид списком"
  >
    <!-- Иконка списка (SVG) -->
  </button>

  <!-- Кнопка сетки -->
  <button
    class="catalog__view-btn catalog__view-btn--grid"
    type="button"
    aria-label="Вид плиткой"
  >
    <!-- Иконка плитки (SVG) -->
  </button>
</div>
```

## 3. CSS (Стилизация)

Стили для вида списком добавлены в конец файла `css/pages/catalog.css`.

Когда активен вид списком, на `div.catalog__grid` скриптом вешается класс `.catalog__grid--list`. Стили переопределяют дефолтное отображение (`grid`).

**Основные изменения при виде списком:**

- Сетка каталога (`.catalog__grid--list`) перестраивается в 1 колонку (`grid-template-columns: 1fr`).
- Карточка товара (`.product-card`) выстраивается горизонтально (`flex-direction: row`).
- Блок с картинкой (галерея) получает фиксированную ширину (например, `220px`), а контентная часть занимает оставшееся пространство (`flex: 1`).
- Описание товара (`.product-card__description`) показывает больше строк (`line-clamp: 3`).
- Футер карточки с ценами и кнопками выстраивается в горизонтальный ряд (`flex-direction: row`).

> Заметка: Стили для стандартного отображения (Сеткой) прописаны в `css/pages/catalog.css` (сам грид) и в `css/modules/product-card.css` (внутренние стили карточки).

## Как расширять функционал в будущем

1. **Смена значения по умолчанию:**
   Достаточно изменить константу `DEFAULT_VIEW` внутри `js/modules/view-toggle.js` с `'grid'` на `'list'`.
2. **Добавление нового вида (например, "компактный"):**
   - Добавить кнопку в HTML с классом `.catalog__view-btn--compact`.
   - В CSS написать стили: `.catalog__grid--compact { ... }`.
   - В `js/modules/view-toggle.js` нужно будет немного доработать код (добавить `isCompactBtn` и логику `view = "compact"`).
