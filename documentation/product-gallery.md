# Документация: Универсальная синхронизированная галерея товара (Product Gallery & Sync)

Данный модуль описывает структуру и алгоритм работы интерактивной галереи на страницах детальной карточки товара (`new-product-kupeli.html`, `new-product-vagonka.html`, `new-product-pechi.html`). Модуль реализован в файле `js/pages/product/gallery.js`.

Модуль решает три ключевые задачи:
1. **Слайдер изображений (Slick)** с кастомной лентой миниатюр, плавным центрированием активного эскиза при прокрутке и адаптивными стрелками навигации.
2. **Интеграция с Fancybox 3** с полной синхронизацией слайдов при открытии (включая корректную обработку клонированных слайдов при бесконечном режиме).
3. **Интеллектуальная система синхронизации опций (Цвет, Размер)**: автоматическое переключение галереи на наиболее подходящее изображение при смене характеристик в выпадающих списках.

---

## 1. Структура разметки (DOM-контракт)

Для корректной работы галереи верстка должна следовать следующей структуре:

### Главный слайдер:
```html
<div class="card-main_slick-one">
  <!-- Слайд 0 -->
  <a href="path/to/image1.jpg" data-slider-fancybox="gallery" data-color="larch_nat" data-size="12x95x2130">
    <img src="path/to/image1.jpg" alt="Описание товара 1" title="Название товара 1" itemprop="image" />
  </a>
  <!-- Слайд 1 -->
  <a href="path/to/image2.jpg" data-slider-fancybox="gallery" data-color="oak">
    <img src="path/to/image2.jpg" alt="Описание товара 2" title="Название товара 2" />
  </a>
</div>
```

### Лента миниатюр и стрелки навигации:
```html
<div class="gallery-nav">
  <button class="gallery-nav__arrow gallery-nav__arrow--prev button-reset" aria-label="Назад"></button>
  
  <div class="gallery-nav__strip">
    <!-- Миниатюра 0 -->
    <button class="gallery-nav__item is-active" data-slide="0" data-color="larch_nat" data-size="12x95x2130" aria-label="Миниатюра 1">
      <img src="path/to/thumb1.jpg" alt="Описание миниатюры 1" />
    </button>
    <!-- Миниатюра 1 -->
    <button class="gallery-nav__item" data-slide="1" data-color="oak" aria-label="Миниатюра 2">
      <img src="path/to/thumb2.jpg" alt="Описание миниатюры 2" />
    </button>
  </div>
  
  <button class="gallery-nav__arrow gallery-nav__arrow--next button-reset" aria-label="Вперед"></button>
</div>
```

## 2. Алгоритм синхронизации опций с галереей

При изменении параметров выбора (выпадающие списки размера или цвета) на уровне карточки товара генерируется глобальное событие `pc:dropdown-change`. Модуль галереи перехватывает это событие и выполняет автоматическое ранжирование слайдов.

### Логика скоринга и оценки соответствия слайда:

1. **Сбор активных спецификаций**: Скрипт сканирует все видимые блоки `.product-hero__field` и извлекает текущие выбранные значения для параметров **Цвет** (`activeSpecs.color`) и **Размер`** (`activeSpecs.size`).
2. **Поиск совпадений (Весовая модель скоринга)**:
   Для каждого оригинального слайда (исключая клонированные `slick-cloned`) рассчитывается итоговый балл соответствия:
   * **Явное совпадение по Цвету (Color Match)**: `+10 баллов` (слайд имеет `data-color`, полностью совпадающий с активным значением `value` или `text` цвета).
   * **Явное совпадение по Размеру (Size Match)**: `+5 баллов` (слайд имеет `data-size`, совпадающий с активным `value` или `text` размера).
   * **Текстовый фолбэк по заголовкам (Semantic Fallback)**: Если явные `data-` атрибуты не заданы, скрипт осуществляет мягкий поиск вхождения текста активных опций внутрь атрибутов изображения `alt` и `title`:
     * Нахождение названия цвета в `title/alt` текста: `+2 балла`.
     * Нахождение размера в `title/alt` текста: `+1 балл`.
3. **Правило дисквалификации (Disqualification)**:
   Любое явное противоречие полностью исключает слайд из кандидатов на показ (`isDisqualified = true`):
   * Если на странице выбрана опция определенного цвета, а слайд привязан к *другому* конкретному цвету.
   * Если выбран конкретный размер, а слайд имеет *другой* фиксированный размер.
4. **Переключение**: Галерея мгновенно совершает переход на слайд, набравший **наибольшее ненулевое количество баллов**:
   `$mainSlider.slick("slickGoTo", bestSlideIndex)`.

## 3. Интеграция с Fancybox 3

Для предотвращения рассинхронизации оригинального слайдера и всплывающего модального окна Fancybox реализована бесшовная интеграция:

* **Индексация клонов**: При включенном `infinite: true` слайдер Slick дублирует элементы верстки. Модуль отслеживает клики по клонированным слайдам, вычисляет их реальный индекс в массиве оригиналов и перенаправляет вызов на настоящий слайд.
* **Группировка**: Fancybox инициализируется динамически. Он собирает адреса изображений *только* из реальных (неклонированных) слайдов, что исключает дублирование кадров при просмотре в модальном режиме.
* **Двусторонняя синхронизация**:
  * При клике на слайд в Slick -> открывается Fancybox именно на этом слайде.
  * При перелистывании внутри Fancybox -> главный слайдер Slick в фоне автоматически прокручивается к текущему активному кадру, синхронизируя состояние страницы.
