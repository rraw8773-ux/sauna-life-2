# План миграции каталога на SlickSlider

## Цель

Полностью перевести галереи карточек каталога на SlickSlider и убрать из актуального проекта прежнюю библиотеку галерей. Внешний вид карточек, поведение галереи, смена изображений при наведении, zoom по двойному клику и адаптивность должны сохраниться.

Браузер и автоматические скриншоты в рамках этой задачи не запускать. Финальная визуальная проверка выполняется вручную.

## Границы задачи

Затрагиваем актуальные файлы проекта:

- `new-catalog.html`
- `js/main.js`
- `js/modules/sliders.js`
- `css/modules/product-card.css`
- `css/pages/catalog.css`
- `documentation/`

После миграции выполнить контрольный поиск по актуальному проекту на название удаляемой библиотеки, ее CDN-пакет и старые классы галереи. В актуальном коде и документации таких упоминаний после миграции быть не должно.

## Фаза 1. Инвентаризация текущего кода галерей

1. Найти все подключения удаляемой библиотеки в `new-catalog.html`.
2. Найти все HTML-блоки карточек со старым контрактом галереи:
   - корневой класс старого слайдера;
   - wrapper старого слайдера;
   - slide старого слайдера;
   - zoom-container старого слайдера;
   - pagination старого слайдера.
3. Найти все CSS-селекторы старого слайдера в `css/modules/product-card.css`.
4. Найти все JS-зависимости от старого конструктора галереи в `js/modules/sliders.js`.
5. Найти проверку старого DOM-контракта в `js/main.js`.
6. Зафиксировать, какие функции должны быть перенесены:
   - один активный слайд;
   - loop;
   - точки пагинации;
   - смена картинки по hover-зонам на десктопе;
   - возврат на первую картинку при уходе мыши;
   - swipe на touch-устройствах;
   - zoom по двойному клику;
   - сброс zoom при смене слайда;
   - корректная работа после AJAX-добавления товаров.

## Фаза 2. Удаление старых подключений

1. Удалить CSS CDN прежней галерейной библиотеки из `new-catalog.html`.
2. Удалить JS CDN прежней галерейной библиотеки из `new-catalog.html`.
3. Обновить комментарии рядом с подключениями, чтобы в них не было названия удаляемой библиотеки.
4. Оставить локальные подключения SlickSlider:
   - `./css/legacy/slick.min.css`
   - `./js/legacy/slick.min.js`
5. Проверить порядок загрузки:
   - `jquery.min.js` должен быть загружен до `slick.min.js`;
   - `slick.min.js` должен быть доступен до запуска нового кода галерей.

## Фаза 3. Замена HTML-контракта галереи

1. В каждой карточке заменить старую разметку галереи на нейтральную разметку карточки.
2. Целевой контракт:

```html
<div class="product-card__gallery">
  <div class="product-card__slider js-product-card-slider">
    <div class="product-card__slide">
      <div class="product-card__image-frame">
        <img
          src="..."
          alt="..."
          class="product-card__image"
        />
      </div>
    </div>
  </div>
  <div class="product-card__pagination"></div>
</div>
```

3. Удалить из HTML все старые классы галереи:
   - корневой класс старого слайдера;
   - wrapper старого слайдера;
   - slide старого слайдера;
   - zoom-container старого слайдера;
   - pagination старого слайдера.
4. Сохранить все текущие `src`, `alt` и порядок изображений.
5. Не менять контент карточек, цены, кнопки, бейджи и характеристики.

## Фаза 4. Настройка SlickSlider

1. Переписать `js/modules/sliders.js` под SlickSlider.
2. Проверять наличие зависимости так:

```js
if (!window.jQuery || !jQuery.fn || !jQuery.fn.slick) return;
```

3. Инициализировать только `.js-product-card-slider`, которые еще не имеют `.slick-initialized`.
4. Базовые настройки Slick:

```js
{
  slidesToShow: 1,
  slidesToScroll: 1,
  infinite: true,
  arrows: false,
  dots: true,
  appendDots: paginationElement,
  adaptiveHeight: false,
  waitForAnimate: false,
  speed: 0
}
```

5. Для desktop hover-режима:
   - `swipe: false`;
   - `draggable: false`.
6. Для touch-устройств:
   - `swipe: true`;
   - `draggable: true`.
7. После инициализации сохранить количество оригинальных слайдов до появления Slick-клонов.

## Фаза 5. Hover-смена изображений

1. Hover-смену включать только на desktop-условии:

```js
window.matchMedia("(min-width: 1024px) and (hover: hover)").matches
```

2. Если в карточке меньше двух изображений, hover-логику не включать.
3. На `mousemove`:
   - получить ширину галереи;
   - разделить ее на количество оригинальных изображений;
   - вычислить индекс зоны;
   - вызвать `slickGoTo(index, true)`.
4. На `mouseleave`:
   - сбросить zoom, если он активен;
   - вернуть галерею на первый слайд через `slickGoTo(0, true)`.
5. Если карточка находится в состоянии zoom, hover-смена не должна переключать изображение.

## Фаза 6. Zoom по двойному клику

1. Реализовать zoom отдельным слоем в `js/modules/sliders.js`, потому что SlickSlider не имеет встроенного zoom-режима.
2. Zoom включается по `dblclick` на `.product-card__image`.
3. При включении zoom:
   - карточке добавить `.is-zooming`;
   - активному фрейму добавить `.is-zoomed`;
   - изображению задать масштаб `scale(3)`;
   - `transform-origin` рассчитать от координаты двойного клика внутри изображения.
4. При повторном `dblclick` zoom выключается.
5. Zoom обязательно сбрасывать:
   - при смене слайда Slick;
   - при `mouseleave` с карточки;
   - при нажатии `Escape`;
   - перед переходом hover-логики на другой слайд.
6. Во время zoom:
   - скрывать неактивные слайды;
   - скрывать точки пагинации;
   - не ломать z-index бейджей и кнопок карточки.

## Фаза 7. Соотношение 3 к 4 и фон фрейма

1. Родительский фрейм изображения должен всегда держать пропорцию `3 / 4`.
2. Фрейм изображения получает светлый фон из переменной проекта:

```css
background-color: var(--color-light);
```

3. Изображение внутри фрейма должно вести себя как в marketplace-паттерне:

```css
.product-card__image {
  width: 100%;
  height: 100%;
  object-fit: contain;
}
```

4. Целевой CSS-контракт:

```css
.product-card__image-frame {
  aspect-ratio: 3 / 4;
  width: 100%;
  background-color: var(--color-light);
  overflow: hidden;
}
```

5. Убрать или переопределить фиксированные высоты, которые конфликтуют с `aspect-ratio`.
6. Отдельно проверить list view, где сейчас есть переопределение высоты галереи в `css/pages/catalog.css`.
7. В grid view и list view карточки должны сохранить визуальную плотность и не растягивать соседний контент.

## Фаза 8. CSS-миграция с сохранением дизайна

1. Заменить селекторы старой галереи на Slick/product-card селекторы:
   - старый wrapper -> `.slick-list` / `.slick-track`;
   - старый slide -> `.slick-slide` / `.product-card__slide`;
   - старый активный slide -> `.slick-current`;
   - старая pagination -> `.product-card__pagination` / `.slick-dots`.
2. Сохранить дизайн точек:
   - размер `6px`;
   - серый фон неактивной точки;
   - активная точка через `var(--color-accent)`;
   - без стрелок.
3. Сохранить нижний отступ под точки.
4. Сохранить поведение `.product-card.is-zooming`, но заменить внутренние селекторы старой галереи.
5. Проверить, что `.product-card__actions` и `.product-card__badges` остаются поверх галереи.

## Фаза 9. Обновление точки входа

1. В `js/main.js` заменить проверку старого DOM-контракта на проверку нового DOM-контракта:

```js
document.querySelector(".js-product-card-slider")
```

2. Оставить вызов `initSliders()`, если имя модуля не меняется.
3. Если модуль будет переименован, обновить импорт и вызов без добавления глобальных функций.

## Фаза 10. AJAX и повторная инициализация

1. После AJAX-добавления товаров через `#product_list.append(...)` новые карточки должны получить SlickSlider.
2. `initSliders()` должна быть идемпотентной:
   - уже инициализированные `.slick-initialized` не трогать;
   - новые `.js-product-card-slider` инициализировать.
3. После добавления новых товаров вызвать `initSliders()` повторно.
4. Если у новых карточек есть dropdown/specs/product-card логика, проверить, не нужна ли повторная инициализация других модулей отдельно. В рамках этой миграции основной обязательный пункт - галерея.

## Фаза 11. Удаление всех упоминаний прежней библиотеки

1. Выполнить контрольный поиск по актуальному проекту на:
   - название удаляемой библиотеки в верхнем и нижнем регистре;
   - CDN-пакет удаляемой библиотеки;
   - старый префикс классов галереи.
2. Удалить или переименовать все найденные актуальные упоминания.
3. Проверить отдельно:
   - HTML-классы;
   - CSS-селекторы;
   - JS-переменные;
   - комментарии;
   - документацию.
4. После миграции в актуальном коде должно остаться только Slick/product-card naming.

## Фаза 12. Ручная проверка

Эту проверку выполняет пользователь вручную.

1. Открыть `new-catalog.html`.
2. Проверить grid view:
   - карточки визуально не изменились;
   - точки работают;
   - hover меняет изображения;
   - при уходе мыши возвращается первая картинка;
   - двойной клик включает и выключает zoom.
3. Проверить list view:
   - пропорция изображения 3 к 4;
   - карточка не ломает сетку;
   - точки и zoom работают.
4. Проверить мобильные ширины:
   - свайп работает;
   - hover-логика не мешает;
   - точки соответствуют активному слайду.
5. Проверить товары, добавленные через AJAX "Показать еще".
6. Проверить консоль браузера:
   - нет ошибок старого конструктора галереи;
   - нет ошибок `slick is not a function`;
   - нет повторной инициализации Slick.

## Критерии готовности

- Прежняя галерейная библиотека полностью удалена из актуального HTML/CSS/JS/документации.
- SlickSlider управляет всеми галереями карточек каталога.
- Дизайн карточек визуально сохранен.
- Hover-смена изображений работает на десктопе.
- Zoom по двойному клику работает и сбрасывается в нужных сценариях.
- Все изображения находятся внутри фрейма `3 / 4`.
- Фрейм изображения имеет фон `var(--color-light)`.
- Изображения имеют `width: 100%`, `height: 100%`, `object-fit: contain`.
- AJAX-добавленные карточки получают рабочую галерею.
- Документация по миграции находится в `documentation/`.
